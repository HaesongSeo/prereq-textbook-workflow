Paste this block at the VERY FIRST LINE of the imported .tex file. It is a
comment, so it is not printed. `import-check.sh` confirms that the string
`IMPORTED CHAPTER` is present, so do not delete that line.

The `ADAPTED:` list is the heart of this block. When the origin is corrected
and the chapter is re-imported, that list is the recipe. Write **what was
changed into what**, not "adapted".

`FIXED:` is a different thing -- the list of mathematical errors found after
the import and corrected HERE (CLAUDE.en.md, "The direction of authority").
An adaptation is something the two books are meant to differ on; a FIXED entry
means the origin is still wrong. Do not mix them. Drop the `FIXED:` section if
nothing was corrected.

% ===========================================================================
% IMPORTED CHAPTER -- a fork, not a copy.
%
% Origin : ../../<project>/tex/chapters/<file>.tex
% Forked : <YYYY-MM-DD>, from the revision recorded in tex/IMPORTS.
%
% The origin refers into its own book and cites its own target paper, so it
% could not be taken verbatim. Everything changed on the way in is listed
% below; nothing else was touched.
%
% ADAPTED:
%   - \cite{<origin key>}  ->  <what it is here>        (the target paper differs)
%   - \ref{<origin label>} ->  \ref{<label in this book>}  (or: sentence made self-contained)
%   - \<origin macro>      ->  \<macro in this book>
%   - chapter header rewritten: what this supports is different here
%
% FIXED: (drop this section if empty -- see CLAUDE.en.md, "the direction of
% authority". These are mathematical corrections made HERE; the origin still
% carries the error.)
%   - <what was wrong>  ->  <what it now says>
%
% AUTHORITY: the origin is authoritative for the mathematics, but an error
% found here is corrected here and listed under FIXED above -- not pushed back
% to the origin. ADAPTED and FIXED are the only things meant to differ from
% the origin. Run `sh tex/import-check.sh` to see whether the origin has moved.
% ===========================================================================
