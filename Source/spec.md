## 의존성 그래프

노드 ID / 이름 / 선행 노드와 간선 종류 / 논문에서의 사용 방식(A–D) / 논문 내 등장 위치

| ID | 노드 | 선행 (간선 종류) | 사용 방식 | 등장 위치 |
|---|---|---|---|---|
| N01 | | N04(정의), N07(증명) | | |

> 사용 방식: A 배경 언급 / B 블랙박스 인용 / C 가설 조작·적용 / D 증명 기법 모방
>
> **「사용 방식」 열에는 글자만 적는다** (`C`, `B/C`). 뜻은 바로 위 줄에
> 있으므로 셀에 풀어 쓰지 않는다. 「챕터 계획」의 「깊이」 열도 같다 —
> `L0`–`L4`로 적는다. 사용자에게 설명할 때 쓰는 평문은 대화창의 것이지
> 이 표의 것이 아니다 (`CLAUDE.md` § 사용자에게 말하는 법).
>
> **간선 종류를 Phase 0에서 반드시 적는다.** `정의` = 선행이 이 노드의 *진술
> 안에* 나온다 (그것 없이 정확히 진술할 수 없다) / `증명` = 선행이 이 노드의
> *증명에만* 쓰인다 (진술은 그것 없이 읽힌다). Phase 1의 등급 전파가 두 경우에
> 다르게 작동한다 (`PHASE1_PROBE_GUIDE.md` §3). 나중에 붙이려면 그래프를 통째로
> 다시 읽어야 한다.

## 원문 교정 기록

> 발견한 오타·부정확한 인용의 **전체 목록**. 미해결 항목이 아니라 확정된
> 기록이며 해당 챕터에 이미 반영되어 있다. 교재에서는 교정해 쓰되 각주로 밝힌다.
> **우리 자신의 기록이 틀린 것으로 드러나면 그것도 여기에 「철회」로 남긴다.**
>
> **이 절은 Phase 6에서 독자용 부록으로 나간다** (`CLAUDE.md` Phase 6 종료 조건).
> 각주는 발견한 자리에 그대로 두고, 목록을 부록에 따로 싣는다 — 원문과 대조하며
> 읽는 독자는 한 곳에 모인 목록을 필요로 한다.

## 확정된 규약

> 프로젝트 전체에 걸치는 편집 결정. 한 번 정하면 매번 다시 묻지 않는다.

- **`refs.bib` 키.** 렌더된 원문 PDF의 alpha 키를 따른다 (독자가 논문과
  대조하기 쉽다).
- **`paper/secNN`의 번호 = 논문의 절 번호.** 순서는 `main.tex`의
  `\include` 순서와 아래 「Phase 5 순서」가 정한다
  (`CLAUDE.md` Phase 5). 한 절이 길면 `sec05a`·`sec05b`로 나눈다.
